impactor-mcpMCP server for the Impactor sideloader

Sign and install iOS apps from your AI agent.

Exposes Impactor's features — Apple ID signing, installs, tweaks, pairing files and auto-refresh — as Model Context Protocol tools.

  • 36 tools covering the Impactor app and plumesign CLI
  • Works with any MCP client — Claude, Cursor, VS Code, Windsurf
  • Built on the official Impactor v2.6.5 crates; the app is not modified
  • Prebuilt for Windows, macOS and Linux
